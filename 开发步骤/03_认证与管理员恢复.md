### 执行记录（2026-10-19）

- 实现：`fitness_app/auth.py` 使用 Flask-Login／WTF-CSRF 和 scrypt，签名 HttpOnly／SameSite=Strict cookie 内的随机认证令牌只存服务端摘要；逐请求核启用、认证版本、绝对到期和临时限制。`fitness_app/app.py` 接数据初始化／身份核验、正式私有密钥、统一错误与请求标识；测试库使用独立密钥位置，不触及个人库。`start.cmd --init-admin`／`--recover-admin` 为实际本机交互入口，密码用隐藏输入，不从参数传入。
- 命令：`.venv\\Scripts\\python.exe -B -m unittest discover -s tests -p test_formal_auth.py -v`，最终 10 项全部通过，退出 0，约 17 秒；只跑本步认证套件，未重复 SDK 推理／数据整集检查／旧原型测试。测试库及诊断临时目录均在项目内并已清理。
- T03-01／02：注册普通用户、大小写冲突、长度／类型／未知 role 字段、密码哈希、保留密码空格、CSRF、未知／停用统一失败、普通用户管理权限和 Host 校验通过。响应不含实际密码／哈希／令牌，公开 `must_change_password` 为必要状态字段。
- T03-03／04：退出／绝对 12 小时到期、原密码错误不写入、改密撤销两个旧登录、旧正式密码在临时状态不可用、30 分钟临时过期、强制改密允许列表及临时成功改密后旧凭据失效均通过；使用测试时钟，不真实等待长时限。任务层只验证撤销通知回调，实际工作线程交 08／10。
- T03-05：首次空库初始化、重复初始化拒绝、服务维护锁、仅恢复有效管理员、取消／确认的实际 CLI 参数及隐藏输入路径通过；普通／停用账号不可恢复，审计无凭据。首位管理员尚未在个人正式库创建，不生成公共默认账号；普通注册在本机初始化前返回 INITIALIZATION_REQUIRED，避免抢先注册堵住初始化条件。
- 修正：初次测试把合法状态字段 `must_change_password` 当密码泄漏，已改为断言真实秘密及精确键；另确保 Host 校验先于匿名鉴权，非法 Host 不被 401 提前响应掩盖。修正后重跑受影响认证套件通过，不以测试误报修改业务字段。
