## 执行步骤

1. 接通管理员账号搜索、筛选、分页与行状态，处理乱序响应和最新查询归属。
2. 实现停用确认、事务版本校验及禁止操作原因，保护自己和最后有效管理员；不扩展解停／删除账号或他人私人记录入口。

## 操作链与异常样例

| 操作链 | 必须验证的实际变化 |
| --- | --- |
| 查询→选择行 | 搜索 A 后立刻搜索 B，A 晚到不得覆盖 B；翻页／筛选后行 ID 与版本仍一致，操作不靠行号定位 |
| 停用→确认→事务 | 取消零变更；禁止对象服务端拒绝；成功才更新行并撤销目标认证。旧版本冲突重读，不能再点一次覆盖 |
| 重置→一次性结果 | 同一命令只生成一个临时密码，旧正式密码不再能登录；受限登录必须改密，错误／过期处理由 03 认证能力实现 |
| 响应丢失→查询回执 | 成功但没收到秘密时只能说明已执行；不得持久保存明文以便重放。再次生成必须明确新确认／新命令 |
| 显示／复制／关闭 | 复制拒绝不得提示成功；关闭清本页秘密并恢复焦点；截图仅取脱敏状态，不能把临时密码写进执行记录 |
