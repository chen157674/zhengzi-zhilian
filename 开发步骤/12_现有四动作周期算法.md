## 分段实现顺序与状态检查

1. 先定义共用适配器输入：动作／变式、单调源时间、目标关联与关节可用状态、姿态和版本、控制／流代次；输入不含 good／bad／GB／PB 答案。输出为阶段、可评估原因及零或多个待提交事件，持久化仍由 06 执行。
2. 为四动作分别落实下表的“起点、离开、转向、返回”可观察条件，建立与质量阈值独立的分段参数。每个参数记录名称、单位、开发来源／样本、候选范围和最终冻结值；无依据不塞一个通用人体角度。
3. 再接入下面的共用状态检查、重置和唯一事件序号；同一输入可被重复调用但不得生成第二事件。
4. 先完成合成序列逻辑，再用开发视频诊断误分段；最后在配置冻结且原始周期真值具备时执行正式计数，不以自身规则输出回填标签。

| 动作 | 必须落实的分段观测 | 边界反例 |
| --- | --- | --- |
| 深蹲 | 可观察站立起点，近侧膝／髋随下蹲变化与回升，返回站立确认；观测侧在周期内固定 | 半蹲未返回、只身体晃动、从下蹲中途入镜；质量幅度问题不自动取消已确认完整周期 |
| 俯卧撑 | 上方支撑起点，近侧肘与躯干下降／推起，返回上方支撑；质量髋位不作为周期是否存在的同一门槛 | 跪姿混入、起身离地、局部遮挡跨过底部；不从开始姿势猜一次 |
| 弯举 | 左右肘各自建立低位起点、屈肘／转向／伸回；同时完成允许输出两个不同侧别事件 | 左臂一完整、右臂半次→左 1／右 0；不能用一侧速度预测另一侧 |
| 硬拉 | 下方准备起点、髋膝／躯干起立转向、回到下方准备；不推断杠铃触地 | 只上拉停顶端／片尾未返回不当完整周期；单次剪辑标签不授权恒报一次 |

| 逻辑阶段 | 转移条件与必须检查 |
| --- | --- |
| 未建立起点 | 仅积累可靠起点证据，不计数；中途入镜先等可确认起点 |
| 起点已建立 | 超过分段噪声带并持续满足离开条件才开始本次候选；微抖动不进入完整周期 |
| 离开／转向 | 记录可观察极值、足够运动证据及真实转向；不要求达到“质量正确”的幅度才允许转向 |
| 返回 | 返回独立的起点确认带且周期证据完整后生成一次事件；更新序号后才能开始下一周期 |
| 暂停／丢失／换代次 | 清除未完成候选；缺失小段如何处理必须有最大 gap 配置，超过后重新建立起点，不拼接半周期；保持已提交次数 |

必须冻结的工程参数包括起点确认／退出滞回、最小可分段运动、转向去抖、最大允许 gap、周期时间约束、侧别和目标关联策略；各参数在开发集合确定，不能用正式质量判项阈值替代。非有限坐标、时间倒退、旧代次及身份不唯一直接走拒判／重置。
