## 入口与页面行为

记录详情“导出PDF”只对已训练、已结束、保存正常且当前有效的本人记录开放；演示、未开始、活动中和旧修订不能新导出。记录列表勾选后可“导出所选PDF”，未选择时“训练报告”查看已有报告；头像菜单也能进入报告历史，不添加第五个主导航。

沿现有浅色风格使用原位弹窗，左上角“返回”。弹窗明确列出所选动作/时间及生成时快照、24小时保留和不调用AI。用户自填负重/难度/备注默认不附；没有可用AI报告时显示简短空态，不放无效选择按钮。有可用报告才列出日期/类型/模型供主动选择，说明所选解释可能引用当时档案或自述，AI文字与检测分区。关闭不取消后台生成，重开可从历史读取。

生成后显示等待/生成中/就绪/失败/过期/删除/来源失效；普通来源更新标“旧快照”，提供明确的“下载旧快照PDF”。下载前重新核对，如果来源刚变化会先提示，再次点击才取旧快照。用户可取消并删除尚在生成的报告，或删除已生成报告，原训练记录不删。超过范围/资源上限、字体缺失、文件校验失败均报错，不显示伪成功。

创建结果不确定时只保留原请求ID和版本/选项，不保存备注正文。刷新后可“核对原请求”；即使来源记录已删除，也先查原回执，不偷偷创建新报告。明确冲突会清掉待确认标记并让用户重新核对来源。切换弹窗范围、关闭或注销后忽略迟到的私有响应；不会在注销后触发旧下载。正文只在当前用户权限下显示。

## 报告内容与事实边界

策略`training-pdf-1`。报告含选定记录、训练开始/结束及原片区间、动作来源（自动/用户指定/未记录）、手动修订身份、保存状态、已开放的参考计数/保持及分侧值、可评估分母与未知、提示/不可评估区间、保存时建议和版本。未开放计数不显示参考区间次数，未训练记录不生成空成果。自由训练ended_early是正常段结束；只有预设target存在才写目标完成前结束，并列目标和实际已保存组数。

区间取原记录事件/观察，按同判项/侧别/状态/规则/机位/时间基准合并重叠范围，不能将合并区间数写成错误次数。保留明确的左右/受影响侧，未知不猜部位方向；上肢裁切等动作专属检测边界可见。模型、姿态规则、能力快照和姿态处理策略摘要可追溯，不输出本机路径或配置密钥。

选两条记录时只在同动作、规则/能力版本、处理策略、侧别、机位和单位下提供观测对照；不把更新计数器/输入处理的效果当作用户改善，不输出无可靠分母的错误概率或因果改善百分比。多条记录独立列出，不机械生成所有两两比较。复测/运动观察按其原参考等级引用，不能因此判断疲劳、肌肉发力、伤病或整体标准。

自填负重保留公斤/磅/档位和单手/单侧/总重/器械口径，未填不写0。AI仅允许主动附入已经成功保存、当前依据仍有效、范围匹配的复盘/对比报告；完整聊天和实时对话不能混入。若AI历史包含所选范围外的其他记录则拒绝，不静默扩展报告范围。复测必要的原提示引用单独计明，不冒充完整纳入原记录。导出不调用供应商、不生成新AI答复，也不产生新的AI用量。

默认不读取账号昵称/头像，不附完整档案、视频、逐帧骨架、聊天、账号凭据或Key。仅在选择相应选项时读取用户备注/已有AI内容；疑似Key脱敏，文字做XML转义，不加载用户文字中的链接/图片。不能显示的特殊字符用Unicode编号，并说明应用原文不变。

## 冻结、持久化和清理

schema11新增`report_exports`，保存有所有人的选项、源版本依赖、生成时快照、PDF BLOB/SHA和生命周期。字体、依赖及所有运行数据留在项目目录；没有公开文件路径或可绕过登录的静态URL。快照最多2MiB；单份最多20条记录、1000个合并问题/未知区间、10MiB PDF、80页，有界执行。过量时要求缩小范围，不无声截断明细。

PDF独立单工作线程、有界队列，不占视觉/AI槽。原请求幂等重放返回原报告；相同有效快照即使不同请求ID也复用现有生成/成品。过期/失败才允许明确的新请求重新生成；查询、重复下载、核对请求从不自动重发AI。每账号同时最多2个生成任务，24小时最多60次新生成，保留PDF及在途最大容量预留不超过64MiB，完成后释放未用预留。记录不会参与报告统计或双计训练次数。

普通记录或备注修改保留原快照，并标旧版本，不改写PDF字节。来源记录删除在同一事务内撤销相应导出并清除PDF/快照正文，迟到生成不能重新发布。被纳入的任何自填字段被清空，或附入AI报告被删/依据变化时，也撤销服务端副本；不附自述/AI的报告不因此读取或暴露这些字段。登录撤销在生成前/分页/发布前复核，未完成任务重启后标失败，不自动再次生成。

服务端副本默认24小时，访问/每60秒清理均检查到期；到期、主动删除和来源失效后清掉PDF和快照正文，保留少量有主生命周期元数据供历史说明。摘要/原视频不删，已由用户下载的本地副本不受服务端撤销。SQLite页可复用，不承诺立即缩小数据库或取证擦除，也不在训练期间自动执行大范围VACUUM。

## API契约

| API | 当前实现 |
| --- | --- |
| `GET /api/v1/reports/export-options?record_ids=...` | 校验1～20个本人当前有效已结束记录，给记录名称/时间/期望版本及范围匹配AI报告，默认不附备注/AI |
| `POST /api/v1/reports/exports` | `record_ids, expected_versions, include_user_notes, include_ai_report, ai_report_ids, format=pdf`；CSRF、幂等键、源版本复核和去重，返回任务身份 |
| `GET /api/v1/reports/exports` | 仅本人最近20份元数据/状态，不返回大PDF或快照正文 |
| `GET /api/v1/reports/exports/<id>` | 同时核对到期/依赖，区分保存状态与current/stale快照身份 |
| `GET /api/v1/reports/exports/<id>/download` | 再鉴权/核对来源/SHA；就绪才返回中文附件名、PDF MIME、no-store及快照身份头，过期/撤销410，他人404 |
| `DELETE /api/v1/reports/exports/<id>` | 期望版本和幂等键；取消/清掉本报告，不删除训练记录 |

AI报告引用检查复用同一历史范围头查询，未复制另一套统计口径；对照复用现有可比统计并可不读用户备注。当前AI提示策略`grounded-coaching-8`，新增mode/target/已完成组与未知周期，明确自由段结束不是没有完成目标，不能由状态推断疲劳。
