状态（2026-10-24）：已修正实际实时页面的开启/暂停/系统中断竞态，13个新增隔离浏览器场景分别通过，受影响的实时提示→单项复测入口回归通过。实际Android/iOS相机、系统权限/锁屏及HTTPS仍待验证，R3-11继续进行中。完整需求引用[手机正式验收](../第三轮优化/开发与验收.md#71-手机直接识别的正式完成条件)，原页面布局和数据契约引用[步骤26](26_手机浏览器与AI交互.md)，复测和冻结AI依据引用[步骤31](31_单项即时复测.md)、[步骤30](30_AI提问时刻与实时画面隔离.md)。

## 已修正行为

修改[实际实时页面脚本](../fitness_app/static/live.js)，未改旧兼容页面、模型权重、判项阈值或数据库schema11。

- 相机尚在授权/播放/获取凭据/创建分析/枚举设备时，切后台或断网立即停止已有媒体流、使旧代次失效；不再受工具条busy状态阻挡。无法取消的授权结果若稍后才返回，直接停止该流，不启动分析。
- 开启各异步阶段及图像解码完成后再次核对代次/页面状态。迟到帧不恢复骨架、问题提示、复测入口或AI当前片段；旧轮询回执也不能修改当前保存故障状态。
- 相机track的ended/mute事件会停止采集、撤去当前反馈并释放分析入口；返回前台或网络恢复不自动开相机，用户明确点击继续后重新取景。保存的训练run保留，新流使用新stream_epoch。
- 媒体时间未推进时不重复提交同一画面；连续5秒没有新媒体时间就关闭相机并提示重新开启。该措施只判断是否有新画面，不把静止人体当作断流，也不代替后端运动证据门控。
- 帧上传和结果轮询均可被中断取消，各自有10秒请求上限。旧预览的并行释放共用一个进行中的请求，回执只清除对应预览，不清除别的流。
- captured_ms取绘制采集画面时的源端单调时间，晚完成的JPEG编码不会把旧画面时间改成编码结束时间。暂停画面可保留最后一帧，并明确显示“已暂停”；不保留正在评估的骨架/部位提示。

## 最小充分验证

[新增浏览器专项](../tests/mobile_camera_lifecycle_check.mjs)使用真实Flask页面、隔离登录及Canvas合成流，分析接口为明确协议替身；无实际设备、GPU推理或供应商请求。测试目录为项目内`.tmp/tests/round3-camera-lifecycle`，每次关闭专属服务/浏览器后清理，并已核验不存在。

先运行opening场景，原代码因设备枚举过程中切后台未停止track而超时失败；修正后只重跑该场景通过。其余场景分批运行，未重复已通过且未受后续改动影响的分支：

| 场景身份 | 实际检查 |
| --- | --- |
| opening | 枚举设备未返回时切后台立即停流，返回后不提交帧 |
| decode | 暂停后解码才完成，不恢复旧画面反馈或AI片段 |
| ended / mute / offline | 三种中断分别停流、停提交、单次释放并保留明确暂停状态 |
| late-poll | 旧GET迟到，即使携带保存失败也不覆盖当前状态 |
| switch | 先停旧相机，再开启新流；自动识别和同一次训练关联保留 |
| create-late | 切后台后创建回执才返回，释放该预览且不开始提交 |
| release-race | 手动暂停与系统后台并发，共用一个释放请求 |
| frozen-video | track仍live但媒体时间不变，5秒检测触发暂停 |
| resume | 返回前台不自动取景，明确继续后新代次接续原训练 |
| capture-time | 注入200ms编码延迟，提交时间仍在编码等待前 |
| encoding-cancel | 编码期间暂停，迟到JPEG不提交 |

执行方式：先载入`scripts/environment.ps1`，使用既有E盘Node运行`tests/mobile_camera_lifecycle_check.mjs`；`FITNESS_CAMERA_LIFECYCLE_SCOPE`支持上述逗号分隔身份，未设置则运行全部。另运行`FITNESS_RETEST_UI_SCOPE=live`的`tests/retest_ui_check.mjs`，确认停流后可进入本人原提示绑定的复测页面，仍需主动开始且默认自动识别；此回归通过，专属测试环境已清理。最终`live.js`语法检查通过。

[390宽中断截图](../data/verification/round3/mobile-camera-interrupted.png)已实际查看：中央合成画面保留明确暂停遮罩，骨架/旧提示撤去，四项导航和继续/结束按钮可见。图中移动方块为工程合成流，不是健身识别效果或手机实机照片。
