## 旧两动作原型（以下为历史说明）

下文描述此前未经确认提前创建的 `server.py`／`web/` 实验，保留文件供追溯，不代表正式应用已完成。其浏览器推理、单人保存和测试结果不能用于正式验收。完整需求以 PRD.md 为准。

### 历史能力（旧原型）

- 徒手深蹲：完整动作周期计数、侧面机位下的参考幅度提示；机位不足时明细标记无法评估。
- 前臂平板支撑：可确认支撑状态下的累计保持计时、明显髋部偏高／偏低参考提示。
- 摄像头、本地视频和一段内置深蹲演示。输入视频只在浏览器中解码和推理，不上传服务器。
- 开始倒计时、暂停／继续、结束；摘要周期保存至本机 SQLite，查看最近 30 条及动作明细。
- 保存失败可重试；重复提交不重复增加次数；重启服务后未正常结束的记录标记为中断。

**这些是未经研究数据集验收的基础规则，不是专业纠错结论。** 没有显示提示不等于姿态全部正确。示例视频没有专家逐次真值，不用于报告准确率。

旧原型当时只覆盖两个动作和单人预览，不具备多用户账号等完整业务。正式项目的12动作、账号隔离、目标、记录、实验和素材状态以本文件上方及各步骤记录为准。

### 历史验证边界（不作为正式验收）

```powershell
node --test tests/analyzer.test.mjs
```

旧记录中的 Python 全量测试发现命令已停止推荐，避免混跑新旧入口及写入不对应的库。正式验证使用上文的逐步骤命令。

历史浏览器验证脚本为 `tests/browser_check.py`，复用本机现有 Playwright 和 Chromium，路径写在脚本中。它要求先在 **8766** 端口启动隔离测试库：

```powershell
python -B server.py --port 8766 --test-db .tmp/test.sqlite3
```

测试会在项目 `.tmp/` 保存浏览器资料及截图，使用模拟摄像头，不调用真实摄像头；通过内置视频验证真实人物的姿态输出和计数。可选的 `.tmp/plank-reference.mp4` 用于前臂平板支撑视频检查，来源为同一参考仓库的 `demo/plank_demo.mp4`，仅测试时按需获取，不额外打包第二段演示。

自动化覆盖状态切换、保存失败重试、模型加载、视频输入及窄窗口布局。规则单元测试使用合成关键点检查边界，不能替代真实准确率评估。现场摄像头、不同体型和机位的效果仍需要用户实测。
