# 正姿智练

基于姿态感知与大模型协同的健身动作纠错与指导平台。

项目面向自主训练的健身初学者，提供实时与视频动作观察、问题片段回看、AI教练、训练计划与执行、动作教学、饮食搭配和成长回顾。浏览器是主要交互入口，服务端统一管理视频任务、证据、工具调用与本人数据。

## Windows 快速开始

1. 克隆本仓库至可写的非系统盘目录。将比赛完整作品包中“源码工程/data”目录合并至仓库的`data/`目录，补齐模型权重与视频资源。
2. 安装 Python 3.12，双击“准备运行环境.cmd”。脚本在工程内创建`.venv`并安装锁定依赖；首次安装需要网络。也可在PowerShell执行`.\scripts\setup.ps1 -Python <Python3.12的完整路径>`。
3. 双击“启动作品.cmd”，浏览器打开本机服务。首次进入可在页面注册邮箱账号并登录。
4. 先体验首页、健身指南、训练计划、饮食与成长页面。新账号从自己的档案和训练开始保存数据。
5. 结束体验时双击“停止作品.cmd”。默认本机端口8765被占用时，程序使用可用端口并打开实际地址。

## 命令行

```powershell
.\start.cmd --no-browser --port 8765
.\start.cmd --stop
.\.venv\Scripts\python.exe -B scripts/verify_resources.py --quick
.\.venv\Scripts\python.exe -B scripts/verify_resources.py
```

`--quick`核对存在性和大小；完整模式逐项计算SHA256。正式体验前建议完成完整校验。

## AI与本地视频识别

云端AI在“设置 → 密钥与偏好”配置本人可用供应商密钥，点击“测试连接”后再使用。密钥由该交付工程自己的本机密钥库加密保存，调用会使用所配置服务的额度。云端调用使用本人配置的凭据。

常规Web功能、档案与训练计划使用基础环境。完整本地视频语义识别还需安装`requirements.video.txt`和`requirements.correction.txt`对应的GPU/姿态依赖；当前记录的本机验证环境为Windows、Python3.12、NVIDIA RTX5060 Laptop与CUDA12.8。CUDA与Torch须与评审电脑硬件匹配。Qwen3-VL-4B、CLIP、BGE及当前姿态/融合资源按清单提供；模型权重与内置视频随比赛完整作品包提供，文件大小和SHA256记录在`交付资源清单.json`。仓库保留模型配置、来源、许可证与资源校验工具。

## 技术架构

浏览器通过应用接口完成账号、训练、视频与AI交互；Python服务组织分析任务、姿态证据、纠错规则与数据持久化。MediaPipe和RTMPose处理姿态关键点，Qwen3-VL参与视频语义理解，BGE索引支持健身知识检索，云端大模型提供AI教练与训练建议。各模块通过统一任务状态向前端反馈进度和分析结果。

## 工程结构

- `fitness_app/`：应用、模板、前端模块、样式、图片与业务规则。
- `data/models/`：固定视觉、检索和动作模型；`data/knowledge/index/`：当前公共知识索引。
- `data/fonts/`：中文报告字体和OFL；`data/presentation-assets.json`：内置媒体来源与摘要。
- `scripts/`：环境、资源、索引与独立体验数据准备工具。
- `tests/`：现有工程测试源码；包含接口协议、任务状态和业务规则测试。
- `third_party/`、`THIRD_PARTY_NOTICES.md`：上游许可、来源与NOTICE。

内置视频、原始分析轨迹与展示标注按资源记录分别保存。上传新视频会创建真实分析任务；训练记录、个人资料和云端调用在首次运行后存入本工程的数据目录。
