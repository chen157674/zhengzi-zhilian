## 离线Git包

`观动知姿代码仓库.bundle`包含main分支及本次标签的可达Git历史，可在没有GitHub访问权限时直接克隆：

```powershell
git bundle verify 观动知姿代码仓库.bundle
git clone 观动知姿代码仓库.bundle guandongzhizi
git -C guandongzhizi checkout v1.0.0-preguidance
```

离线包保存代码、文档、公开演示与提交记录。模型按资源清单恢复，个人数据库和认证文件在首次启动时生成。安装步骤见README。
